# Video Club

Este proyecto es un sistema de administración para un video club, desarrollado como parte de las prácticas de la materia Programación de Plataformas Emergentes. 

## Inicializando

Estas instrucciones te permitirán obtener una copia del proyecto y ejecutarlo en tu máquina local para propósitos de desarrollo y pruebas.

### Pre-requisitos

Herramientas y lenguajes necesarios para ejecutar el proyecto, enfocados en tecnologías de plataformas emergentes como Go o React Native.

```bash
# Ejemplo de dependencias a instalar
- Git
- Node.js (para el entorno frontend)
- Go (para los microservicios del backend)
```

### Instalación

Serie de pasos para configurar el entorno de desarrollo local:

Clonar el repositorio:
```bash
git clone https://github.com/Jonathan-Meixueiro/video-club.git
```

Ingresar a la carpeta del proyecto:
```bash
cd video-club
```

Instalar las dependencias requeridas:
```bash
npm install
```

Ejecutar el entorno de desarrollo para visualizar el sistema:
```bash
npm start
```

## Corriendo las pruebas

Las pruebas automatizadas aseguran que los módulos de renta y administración funcionen correctamente.

### Desglose de pruebas de extremo a extremo

Verifican el flujo completo de la aplicación, como el proceso de registro de un cliente y la renta de una película.

```bash
npm run test:e2e
```

### Y pruebas de estilo de desarrollo

Garantizan que el código escrito mantenga un estándar y formato limpio.

```bash
npm run lint
```

## Despliegue

Para desplegar este proyecto en un sistema en vivo, asegúrate de configurar las variables de entorno de producción y utilizar un servicio de alojamiento en la nube compatible con la arquitectura del sistema.
